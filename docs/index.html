Tiler

Draw the layout of your windows in a fast, cool manner.

A free grid window manager for Mac: snap any window to any part of the screen by drawing it.

macOS 13+ Free & open source
Download GitHub

How it works

1
Drag
Start dragging a window like you usually would
2
Trigger
Press Space (or your chosen trigger) — the grid appears
3
Draw
Draw the area you want the window to fill
4
Snap
Release — the window snaps instantly

Install

Homebrew

brew install VlatkoMilisav/tap/tiler

Manual

Download Tiler.dmg, open it, and drag Tiler into Applications.

The app isn't notarized because $99/year for an Apple developer certificate is a scam. macOS will complain — go to System Settings → Privacy & Security and click "Open Anyway".

FAQ

What is Tiler?
A free, open-source window manager for macOS. Instead of memorizing keyboard shortcuts or picking from fixed halves and thirds, you draw the area a window should fill on a grid overlay.
How is it different from Rectangle, Magnet or Divvy?
Rectangle and Magnet snap to preset positions. Divvy uses a grid but opens from a hotkey in a separate panel. Tiler puts the grid over the screen while you drag the window, so you move and resize in one motion. It is free and open source.
Is there a WindowGrid for Mac?
Tiler is a macOS take on WindowGrid for Windows: drag a window, press a key, draw the target cells.
Which macOS versions are supported?
macOS 13 Ventura and later. The release build is Apple Silicon only; Intel Macs can build from source.
Why does it need Accessibility access?
macOS only lets apps move and resize other apps' windows through the Accessibility API. Tiler does not read window contents. Its only network call is checking GitHub for a newer release.
